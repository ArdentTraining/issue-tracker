# Manual screenshots

Loaded lazily by the in-app user manual (the `?` at the foot of the rail in
`index.html`). Nothing in these files is real.

**This repository is public.** Every student name, email address, report and
lesson reference in these screenshots is invented, and every one of them must
stay that way. If a screenshot needs replacing, capture it against demo data,
never against the live board.

The demo people are Alan Prentice, Marie Fenwick, Douglas Ray, Priya Sandhu,
Tom Beckett and Jan Kowalczyk, all at example.com. The instructor names are our
own, which is fine, and the courses and lesson codes are real, which is also
fine: neither identifies a student.

A missing file is not an error. The manual degrades a figure it cannot load
into a quiet "screenshot to come" box, so a half-finished set is safe to ship.
